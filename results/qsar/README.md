# QSAR Biodegradation | Experimental results

This folder contains the results of the binary classification experiment on **QSAR Biodegradation**, evaluated under missing-data shift and post-hoc probability calibration.

## Experimental overview

- Dataset: 1,055 observations, 41 predictor features; binary target (`RB` vs `NRB`).
- Models: TabPFN-v2, TabICLv2, TabDPT, CatBoost, and MLP.
- Repeated splits: seeds **42, 43, 44**.
- Test conditions: reference (no artificial missingness), random cell-wise missingness (10%, 30%, 50%), and feature-wise unavailability (10%, 30%, 50%).
- Calibration: no additional calibration, reference temperature scaling (Reference TS), and missingness-augmented temperature scaling (Augmented TS).
